Microsoft Sentinel — SOC Fundamentals

Detection rules • KQL • Dashboards • Incident triage

Project Summary

Built analytic rules and dashboards in Microsoft Sentinel. Tuned detections to reduce false positives and created KQL-based playbooks for suspicious PowerShell and process injection detection.

Technical Details

  • Created KQL rules to detect anomalous command lines and remote execution patterns.
  • Built Sentinel workbook dashboards to surface lateral movement indicators and unusual authentication patterns.
  • Tested detections using synthetic attack telemetry and iteratively tuned rule thresholds.

Example KQL Snippet

SecurityEvent
| where EventID == 4688
| where NewProcessName contains "powershell.exe" and CommandLine has_any("Invoke-Expression","DownloadString")
| extend Account = tostring(Account)
| project TimeGenerated, Computer, Account, NewProcessName, CommandLine

(This is an example detection snippet — tailor it to your environment.)

Outcome

Reduced noise for simulated incidents by ~30% and improved mean time to detect in lab simulations. Documented playbook with triage steps and evidence collection commands.
